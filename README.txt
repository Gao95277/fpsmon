FPS 监控
========

双击 fpsmon.exe 就能用。屏幕最顶端会出现一条横条，没有安装过程，没有设置界面。


显示什么
--------

  FPS       最近 1 秒的平均帧率
  1% low    最近 30 秒里最慢那 1% 帧的平均帧率
  CPU       整机 CPU 占用
  GPU       显卡 3D 引擎占用
  RAM       物理内存占用

它跟着「当前最前面的窗口」走。那个窗口在向屏幕交帧，就显示帧数；没在交帧
（桌面、资源管理器、Office 这类），FPS 和 1% low 显示 --，其余三项照常显示。
切换窗口时会自动清空重算，不会把上个程序的数字带过来。


托盘菜单
--------

右键点托盘图标：

  显示显示层 / 隐藏显示层
  位置           屏幕顶端、屏幕底端
  开机自动启动
  退出

横条紧贴屏幕顶边、水平居中，高约 30 像素，不会挡住画面里的东西。
它完全不接收鼠标，点击、拖动、滚轮全部穿透到下层窗口，打游戏时不会被它
挡到操作。所以位置是通过托盘菜单切换的，不是拖动的。


已知限制
--------

1. 独占全屏下看不见
   就是那种切换分辨率、屏幕会黑一下的真全屏。无边框全屏和窗口化都正常。
   现在的游戏基本都默认无边框，一般碰不到。

2. 数字大约每 1 秒刷新一次
   数据来自 Windows 系统事件流，系统是按秒批量投递的，这是它的固有节奏。
   数值本身是逐帧精确计算的，不是抽样估算，只是刷新慢一点。平均帧率本身
   就是「1 秒内的统计量」，1 秒一跳也算自洽。

3. 模拟器里看到的是模拟器输出帧率
   比如 MuMu 跑逆水寒手游，读到的帧率是模拟器往屏幕输出的帧率，不是游戏
   内部渲染的帧率。模拟器锁 60 输出时，就算游戏内部掉到 30，面板上照样
   显示 60。这个只能看模拟器自己的性能面板。


关于反作弊
----------

这个程序不在游戏进程里运行。不注入、不读写游戏内存、不 hook 图形接口，
游戏进程里没有任何一个属于它的模块。

它读的是 Windows 自带的诊断事件流，任务管理器、性能分析工具用的是同一类
机制。就风险等级而言，跟「开着任务管理器玩游戏」是同一档。它不是微星小
飞机那种注入式 overlay，所以不存在被判定成作弊软件的前提。


资源占用（实测）
----------------

  CPU    0.31% 单核   0.026% 整机（12 线程）
  内存   43 MB

单个 exe，无运行时依赖，不需要安装，不需要 .NET 或 VC 运行库。
想换个地方放，直接把这个 exe 挪走就行。


出问题了怎么办
--------------

如果 FPS 一直显示 --，但 CPU/GPU/RAM 都正常，说明事件流没读上。
先确认是不是正在玩游戏（独占全屏的话看不见，也不会读到数）。
如果确认是权限问题，退出后右键「以管理员身份运行」再试。
